# GASTRONOME CLUB - 会員制レストランポータル

招待された会員だけが利用できる、美味しいお店を共有するポータルサイトです。

## 機能

- **招待制の会員登録** - 既存会員が発行する招待コードでのみ登録可能
- **レストラン共有** - 会員がおすすめのお店を登録・共有
- **レビュー・評価** - 5段階の星評価とコメントでレビュー投稿
- **お気に入り** - 気になるお店をブックマーク
- **検索・フィルター** - ジャンル、エリア、キーワードで絞り込み
- **管理パネル** - 管理者向けの会員・招待コード管理

## セットアップ

```bash
npm install
npm start
```

サーバーが `http://localhost:3000` で起動します。

## 初期ログイン

| ユーザー名 | パスワード |
|-----------|-----------|
| admin     | admin123  |

起動時にコンソールに利用可能な招待コードが表示されます。

## 技術スタック

- **バックエンド**: Node.js, Express
- **データベース**: SQLite (better-sqlite3)
- **認証**: express-session, bcryptjs
- **フロントエンド**: HTML, CSS, JavaScript (バニラ)
